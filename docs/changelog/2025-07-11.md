# Changelog — 2025-07-11

## Architecture Refactor: Separate JIRA, Agent, and Core Service Layers

Major refactoring to separate the codebase into three clear layers: **JIRA Integration**, **Agent/AI**, and **Core Service**. The goal is to make the project structure understandable for new contributors and maintainable as an open-source project.

---

### Breaking Changes

#### API URL Restructure

All API endpoints have been reorganized into focused route groups:

| Old Endpoint | New Endpoint |
|---|---|
| `/api/v1/scrum/suggestions` | `/api/v1/backlog/suggestions` |
| `/api/v1/scrum/pushSuggestionsToJira` | `/api/v1/backlog/pushToJira` |
| `/api/v1/scrum/backlog/push` | `/api/v1/backlog/push` |
| `/api/v1/scrum/backlog/generated/:id` | `/api/v1/backlog/generated/:id` |
| `/api/v1/scrum/backlog/generated/:id/stories/:storyId` | `/api/v1/backlog/generated/:id/stories/:storyId` |
| `/api/v1/scrum/backlog/generated/:id/approve` | `/api/v1/backlog/generated/:id/approve` |
| `/api/v1/scrum/backlog/history` | `/api/v1/backlog/history` |
| `/api/v1/scrum/backlog/search` | `/api/v1/backlog/search` |
| `/api/v1/scrum/chat/*` | `/api/v1/chat/*` |
| `/api/v1/scrum/prd/*` | `/api/v1/prd/*` |
| `/api/v1/scrum/standup` | `/api/v1/scrum/standup` *(unchanged)* |
| `/api/v1/scrum/retrospective` | `/api/v1/scrum/retrospective` *(unchanged)* |
| `/api/v1/scrum/webhooks/jira` | `/api/v1/scrum/webhooks/jira` *(unchanged)* |

#### Removed Endpoints

- `GET /api/v1/scrum/chat/history` — duplicate of `/api/v1/chat/:sessionId/messages`
- `POST /api/v1/scrum/chat` (`chatWithScrumMaster`) — broken endpoint that called `chatWithAI` with wrong arguments

### Added

- **`integrations/jira/services/jiraClient.js`** — Added `searchIssues()` and `createIssue()` SDK helpers to replace raw axios + Basic Auth patterns
- **`integrations/jira/index.js`** — Barrel export for all JIRA integration services
- **`controllers/backlogGeneration.controller.js`** — Extracted PRD → backlog generation from scrum.controller
- **`controllers/scrumReports.controller.js`** — Extracted standup and retrospective report generation
- **`controllers/jiraPush.controller.js`** — Extracted JIRA push logic
- **`routes/backlog.routes.js`** — Dedicated backlog route file (`/api/v1/backlog/*`)
- **`routes/chat.routes.js`** — Dedicated chat route file (`/api/v1/chat/*`)
- **`routes/prd.routes.js`** — Dedicated PRD route file (`/api/v1/prd/*`)
- **`docs/changelog/`** — Changelog directory

### Changed

- **`controllers/backlog.controller.js`** — Replaced raw axios + Basic Auth with `jiraClient` SDK calls
- **`services/ai/tools/backlog.tool.js`** — Replaced raw axios + Basic Auth with `getJiraClient` + `searchIssues`
- **`backlog-generator/nodes/jiraFetch.js`** — Uses `searchIssues` helper for bug count query
- **`controllers/generatedBacklog.controller.js`** — Updated import path for pushWorker
- **`services/pushWorker.js`** — Moved to `integrations/jira/services/pushWorker.js`
- **`routes/scrum.routes.js`** — Slimmed down to only standup, retrospective, and webhook routes
- **`server.js`** — Route registration reorganized with clear grouping comments
- **`client-v2/src/api/chat.ts`** — Updated all 6 API URLs from `/api/v1/scrum/chat/` to `/api/v1/chat/`
- **`client-v2/src/api/scrum.ts`** — Updated all 16 API URLs to match new route structure

### Removed

- **`controllers/scrum.controller.js`** — "God controller" (272 lines) that mixed JIRA, AI, and business logic. Split into 3 focused controllers.
- Dead endpoints: `chatWithScrumMaster` (broken duplicate) and `getChatHistory` (redundant)

### Fixed

- **Competing JIRA auth patterns** — Eliminated raw Basic Auth from `backlog.controller.js` and `backlog.tool.js`. All JIRA calls now go through the OAuth2-based `jiraClient.js` SDK.
- **Mid-file imports** — `scrum.controller.js` had imports scattered at lines 173 and 235. All new controllers have clean top-of-file imports.
